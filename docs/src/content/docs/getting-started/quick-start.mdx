This page walks you through writing a small tasq file and running it. It assumes you have [installed tasq](../installation/).

{/* VERIFY everything marked below against the real CLI: file name, `tasq run`, how tasks are listed, how arguments are passed. */}

<Steps>

1. **Create a file**

   Create a file named `tasq` and add your first task:
    <Code code={hello} lang="tasq" title="tasq"/>

   A task has a name and a body in braces. The `$` runs a command, and the backticks hold the command line.

2. **Run it**

   ```sh
   tasq hello
   ```

   You should see `Hello from tasq!` printed.

3. **Add a parameter**

   Tasks can take parameters with a type and an optional default value:

    <Code code={greet} lang="tasq" title="tasq"/>
   Values inside `{ }` in a backtick string are substituted into the command.

   ```sh
   tasq greet # Hello, world!
   tasq greet tasq # Hello, tasq!
   ```

4. **Add a dependency**

   List the tasks that must run first in square brackets after the name:

   ```txt
   task build {
     $`echo "building..."`
   }

   task release [build()] {
     $`echo "releasing..."`
   }
   ```

   Running `release` runs `build` first.

   ```sh
   tasq release
   ```

</Steps>

<Aside type="tip">
  Run `tasq --help` to see every command and option.
</Aside>
